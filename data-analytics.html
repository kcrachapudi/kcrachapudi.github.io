Recruiter Analytics Dashboard

Live Demo ↗

This project is a high-performance data visualization tool designed to help HR teams and talent acquisition managers optimize their hiring pipeline.

  • Automated Data Processing: Seamlessly ingests raw Excel datasets and performs real-time data cleaning, including date normalization and status mapping.
  • Dynamic KPI Tracking: Instantly calculates mission-critical metrics such as Total Applications, Hire Rate, and Average Time-to-Hire.
  • Interactive Hiring Funnel: Visualizes the candidate journey from application to hire, pinpointing exactly where the highest drop-off occurs in the pipeline.
  • Source Effectiveness Analysis: Evaluates which platforms yield the best talent by comparing Cost-per-Hire and conversion rates across different sourcing channels.
  • Recruiter Performance Benchmarking: Features side-by-side comparisons of recruiter speed and volume, tracking efficiency from the first interview to the final offer.
  • Multi-Dimensional Filtering: Allows users to drill down into specific recruiters or sources using sidebar controls for targeted performance reviews.
  • Time-to-Fill Metrics: Provides deep-dive time analysis to identify pipeline lag and improve the overall speed of the recruitment cycle.
  • Data Transparency: Includes expandable sections for auditing both the raw and filtered datasets directly within the interface.
  • Insight Generation: Automatically highlights key trends, such as high-converting referral sources and recruiter-specific bottlenecks.
  • Scalable Architecture: Built with a modular Python/Streamlit framework, making it easy to adapt for larger HRIS data exports or cloud-based databases.
