Live Demo ↗

Unsupervised ML-powered log anomaly detection dashboard simulating a production microservice log stream and flagging anomalous events using Isolation Forest — no labelled training data required.

  • Generated synthetic log streams across 7 microservices with correlated anomaly signals — response time spikes, CPU saturation, HTTP error codes — matching real production incident patterns.
  • Applied Isolation Forest (scikit-learn) with configurable contamination rate to detect anomalies across 5 features without pre-labelled data.
